# Эпоха Легенд

## Скачать игру (Windows)

**[EpohaLegend-Windows.zip](https://github.com/kunst123123-ux/epoha-legend-updates/raw/main/EpohaLegend-Windows.zip)**

1. Распакуйте архив в любую папку.
2. Запускайте **`EpohaLegend.exe`** (это лаунчер).
3. При первом запуске лаунчер скачает игру (~200 МБ) и запустит её. Дальше игра обновляется сама:
   новая версия скачивается в фоне, в главном меню появляется кнопка «Перезапустить и обновить».

> Windows может показать окно SmartScreen: «Подробнее» → «Выполнить в любом случае».

macOS: пока только полной сборкой вручную, без автообновления.

---
Служебные файлы обновлений: `version.json`, папка `win/`.
